# ForgeCycle · مختبر المشاريع الذكي

تطبيق محلي لـArch Linux: المنسّق يسأل عن الفكرة، أنت توافق على المواصفات، البنّاء يكتب الملفات، والمراجع يدققها على عدة جولات. واجهة عربية تفتح تلقائيًا في المتصفح. التطبيق يعمل بخادم محلي على `127.0.0.1`، ولا يحتاج Node أو حزم Python إضافية.

## تنزيل وتشغيل على Arch

إذا حمّلت النسخة المضغوطة:

```bash
unzip forgecycle-desktop.zip -d forgecycle-desktop
cd forgecycle-desktop
./run.sh
```

أو استنسخ المشروع من GitHub:

```bash
git clone https://github.com/ahmedkdbdh1354/forgecycle-desktop.git
cd forgecycle-desktop
./run.sh
```

إذا ظهرت مشكلة صلاحيات: `chmod +x run.sh`. افتح الرابط الذي يظهر في الترمينال إذا لم يفتح المتصفح تلقائيًا. أوقف التطبيق بـ `Ctrl+C`. يلزم Python 3.10 أو أحدث، و`git` للتنزيل، ومتصفح رسومي. قبل إعداد الـAPI تستطيع تجربة المسار كاملًا باختيار **تجربة بلا API** في الإعدادات، ثم **انسخ إلى الأدوار الثلاثة**.

## إعداد API

1. افتح **الإعدادات** واختر المزوّد، أو **تعرّف تلقائي آمن**.
2. أضف مفتاح API، ثم اضغط **جلب النماذج** واختر نموذجًا. مفتاح API لا يحتوي عادة اسم النموذج، لذلك لا يمكن استخراجه منه وحده.
3. اختر **انسخ إلى الأدوار الثلاثة** للبدء بمفتاح واحد، واحفظ. تستطيع بعدها تخصيص نموذج أو مزوّد مختلف لكل دور.
4. في **الاستوديو** اكتب الفكرة، أجب الأسئلة، راجع المواصفات، وحدد مجلد المشروع إن رغبت.

المزوّدون: Kimi، OpenAI Responses، Gemini generateContent، Anthropic Messages، وأي خادم يقدم OpenAI-compatible `/v1/models` و`/v1/chat/completions` (مثل خادم محلي). التعرف الآلي يعمل فقط مع البوادئ أو العناوين الواضحة؛ بعض المفاتيح تبدأ بـ`sk-` لدى أكثر من مزوّد، ولهذا يطلب منك اختيار المزوّد بدل إرسال المفتاح إلى عدة خوادم. قد لا يقدّم خادم متوافق قائمة النماذج؛ أدخل اسم النموذج يدويًا عندها. توفّر الموديلات وصلاحياتها مرتبط بحسابك لدى المزوّد.

## دورة العمل

- **المنسّق:** 3–6 أسئلة أولًا، ثم ملخص ومعايير نجاح قابلة للتعديل؛ ينتظر موافقتك الصريحة.
- **البنّاء:** يكتب ملفات كاملة داخل مجلد المشروع؛ يمنع مسارات الخروج وملفات المفاتيح. يحفظ النسخ السابقة داخل `.forgecycle/history` في مجلد المشروع.
- **الفحص:** تدقيق صياغة Python تلقائيًا، واختبارات/بناء npm إذا كانت الاعتماديات مثبتة والسكربتات متاحة. يمكنك إضافة أمر فحص إضافي في شاشة الموافقة.
- **المراجع:** يرى الملفات ونتائج الفحص؛ إذا وجد مشكلة يعيدها إلى البنّاء. تتوقف الدورة عند الموافقة، أو حد الجولات/الطلبات، أو حين تطلب الإيقاف.

الواجهة تعرض التقرير بعد انتهاء الجولات، بما فيها حالات الفشل. **موافقة النموذج ليست بديلًا لاختبارات حقيقية**؛ أضف اختبارات مشروعك للحصول على مراجعة أقوى. تنفيذ أمر الفحص يشغّل كود المشروع داخل حساب المستخدم، فشغّل مشاريع تثق بها. ملفات المشروع ومحتوياتها ذات الصلة تُرسل إلى مزوّد API المُختار.

## التخزين والخصوصية

- تُحفظ المفاتيح محليًا في `~/.config/forgecycle/settings.json` بصلاحيات `0600`. لا تعرضها الواجهة بعد الحفظ، ولا تدخل في Git.
- تسجل الجلسات في `~/.config/forgecycle/runs/` وتظهر في قسم النشاط. الواجهة متاحة محليًا فقط مع حماية الطلبات التي تغيّر الحالة.
- رقم التكلفة الظاهر تقدير لـKimi بسعر المدخلات والمخرجات القياسي؛ قد تنقص الفاتورة بسبب التخزين المؤقت أو تختلف بسبب المزوّد والضرائب. حدد حد طلبات مناسبًا قبل استخدام مشروع كبير.

## اختبار محلي

```bash
python3 -m unittest discover -s tests -v
python3 -m compileall -q forgecycle app.py
```

هذا مشروع تجريبي أولي مستقل، لا يدمج مستودع Multi-Agent Builder القديم تلقائيًا.
